# Version 1.2.0 Release Notes

## 21 Blaze 1.2.0

The first public release of 21 Blaze — fast Solo blackjack-style lane gameplay
with earnable Blaze Locker cosmetics and Blaze Rewards.

### New in 1.2.0

- **Solo timed mode** — 2:00 runs, four lanes, multiplier streaks, and classic 21 Blaze scoring
- **Countdown** — GET READY fire-ring start sequence centered on the gameplay board
- **Pause, resume, and restart** — full match control without losing progress unfairly
- **High scores** — local history plus verified global leaderboard when online
- **Blaze Locker** — earn Blaze Coins and unlock card backs, lane effects, arena tints, and profile frames
- **Blaze Rewards** — daily login rewards and missions (server-backed when online)
- **Visual themes** — Classic plus earnable Ember collection themes and board effects
- **Settings** — sound, haptics, and Reduced Motion
- **How to Play** — in-app rules reference

### Improvements

- Startup hardening for iOS and Android standalone builds (visible rescue screen, lazy shell load)
- Android countdown ring alignment fix (board-relative overlay)
- Kotlin 2.3 compatibility for Android AdMob SDK

### Not in this release

- In-app purchases and paid coin packs (RevenueCat disabled)
- Rewarded-ad coin grants (server verification pending)
- Daily Challenge, ranked play, live duels, friends, and chat
- Player level progression screen

### Ads

- Optional interstitial ads on natural Solo transitions only (never during gameplay or countdown)
- TestFlight and internal builds use Google test ad units

For support, use in-app Feedback from Settings.
