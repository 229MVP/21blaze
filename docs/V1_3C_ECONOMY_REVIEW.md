# Version 1.3C — Economy Review

## Version 1.3 Challenge additions (per active competitive week)

| Source | Casual (1–2 days) | Active (5–7 days) | Highly competitive |
|--------|-------------------|-------------------|---------------------|
| Participation | 20–40 coins, 75–150 XP | 100–140 coins, 375–525 XP | 140 coins, 525 XP |
| Daily placement | 0–75 | 125–400 | 200+ (top ranks) |
| Weekly claim | 0–75 | 150–250 | 600 (Inferno tier) |
| Streak milestones | 0–50 | 50–125 | up to 925 coins (one-time milestones) |

## Assessment

- Challenge rewards supplement Solo/missions without replacing them — participation is modest (20 coins vs V1.1 match economy).
- Weekly Inferno tier (600 coins) is a meaningful weekly ceiling for dedicated players but requires seven strong days.
- No change recommended to documented amounts in this RC — monitor TestFlight wallet growth.
